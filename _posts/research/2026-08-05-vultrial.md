## Summary

기존 LLM 기반 소프트웨어 취약점 탐지 기법은 대부분 단일 LLM의 추론 결과에 의존하기 때문에, 정상 코드와 취약 코드가 구조적으로 매우 유사한 경우(paired vulnerable/benign functions) 잘못된 판단을 내리는 한계가 있다. 본 연구는 이러한 문제를 해결하기 위해 실제 법정 재판(Mock Court) 과정을 모방한 LLM 기반 Multi-Agent 프레임워크인 **VulTrial**을 제안했다.

VulTrial은 실제 법정의 역할을 그대로 반영하여 네 가지 에이전트로 구성된다.

- **Security Researcher (검사)**: 코드에서 잠재적인 취약점을 탐지하고 공격 가능성을 적극적으로 주장
- **Code Author (변호인)**: 해당 코드가 안전한 이유를 제시하거나 상대측 주장을 반박
- **Moderator (판사)**: 양측의 핵심 주장을 정리하고 토론의 흐름을 관리
- **Review Board (배심원)**: 모든 근거를 종합하여 최종적으로 취약 여부를 판정

이처럼 토론(Debate) 기반의 협력적/적대적(adversarial) 추론 구조를 통해 단일 LLM보다 신뢰성 높은 판단을 수행하도록 설계되었다. 

또한 본 연구는 단순히 여러 에이전트를 병렬로 사용하는 데 그치지 않고, 각 역할에 특화된 프롬프트와 **Role-specific Instruction Tuning**을 적용해 에이전트의 전문성을 강화했는데, 특히 판사(Moderator) 역할에 대해 단 50개의 페어 샘플만으로 Instruction Tuning을 수행한 결과, 튜닝 이전 대비 P-C(Positive-Correct) 지표가 15점, Single-Agent 대비 56점, 기존 Multi-Agent 방법 대비 52점 향상되는 것을 확인했다. Ablation Study에서는 Security Researcher/Code Author/Moderator/Review Board 4개 에이전트를 각각 제거해가며 실험한 결과, 네 에이전트 모두가 최종 성능에 필수적임을 밝혔다. 특히 Moderator와 Review Board가 함께 파인튜닝된 경우 Review Board가 Code Author의 주장 쪽으로 지나치게 편향(over-alignment)되는 경향도 발견되어, 향후 연구에서는 에이전트별 학습을 분리할 필요가 있다고 언급하였다.

실험은 **PrimeVul(Paired)** 데이터셋을 대상으로 GPT-3.5, GPT-4o, 그리고 오픈소스 모델인 **LLaMA-3.1-8B**(사내 배포 가능한 모델) 등 다양한 LLM을 사용하여 수행되었다. GPT-4o 기준으로 VulTrial은 기존 Single-Agent 및 Multi-Agent 베이스라인 대비 정답 페어 수를 각각 41개, 37개 더 늘렸으며, 이는 기존 최고 성능 대비 약 두 배(102%) 가량의 성능이 개선되었다. 이는 적절한 역할 분담과 토론 구조를 적용하면 상대적으로 저렴한 GPT-3.5 기반 VulTrial이 단일 GPT-4o보다도 높은 성능을 달성할 수 있음을 보여주어, 성능과 비용 효율성을 동시에 확보할 수 있음을 입증했다.

VulTrial의 실용성은 정적 벤치마크를 넘어섬을 검증했다. 연구진은 이 프레임워크를 실제 오픈소스 코드베이스에 적용하여 이전에 알려지지 않은 취약점(예: CVE-2025-49000)을 발견하고 이를 실제로 컨펌받는 데 성공했으며, 이는 VulTrial이 학습 데이터를 넘어 일반화될 수 있음을 시사한다. 아울러 생성된 설명(Explanation)의 품질을 CoT(Chain-of-Thought) 방식과 비교하는 자동·수동 평가도 수행하여, VulTrial이 더 정확하고 신뢰할 수 있는 근거를 제시함을 확인했다. 

이 연구의 핵심 아이디어는 취약점 탐지를 서로 다른 입장의 전문가들이 증거를 제시하고 반박하는 **'의사결정 과정(Adjudication Process)'**으로 재해석했다는 점이다. 이를 통해 LLM의 추론 과정을 체계화하고, 최종 판단의 **설명 가능성(Explainability)**과 **신뢰성(Reliability)**을 동시에 향상시켰다.. VulTrial은 이후 Multi-Agent Debate 기반 취약점 탐지 연구(예: Strategic Heterogeneous Multi-Agent Architecture, Phoenix의 Behavioral Contract Synthesis 등)에서 지속적으로 비교 대상 baseline으로 인용되며, Debate·Multi-Agent Reasoning·Explainable Vulnerability Detection 방향성에 큰 영향을 줬다.

## Key Contributions

- Mock-Court(법정 재판) 개념을 적용한 LLM 기반 Multi-Agent 취약점 탐지 프레임워크(VulTrial) 최초 제안
- Security Researcher(검사) · Code Author(변호인) · Moderator(판사) · Review Board(배심원)의 역할 기반 적대적(adversarial) 협력 추론 설계
- Debate 기반 Evidence-Centered Reasoning을 통해 설명 가능한(explainable) 취약점 탐지 구현 및 CoT 대비 우수한 설명 품질 검증
- 50개의 소량 페어 샘플만으로 Role-specific Instruction Tuning을 적용, P-C 지표 최대 56점 향상
- 4개 에이전트 각각의 필요성을 검증한 Ablation Study 수행 (에이전트 제거 시 성능 저하 및 편향 현상 분석)
- PrimeVul(Paired) 벤치마크에서 GPT-4o 기준 기존 Single/Multi-Agent 대비 최대 약 2배(102%) 성능 향상
- 저비용 모델(GPT-3.5)에 VulTrial을 적용해 고비용 Single-Agent GPT-4o보다 높은 성능·낮은 비용 동시 달성
- 실제 오픈소스 코드베이스에서 신규 제로데이 취약점(CVE-2025-49000 등) 발견 및 컨펌으로 실전 활용 가능성 입증

## Paper Review
Paper Review

- 기존 LLM 기반 소프트웨어 취약점 탐지 연구는 주로 Fine-tuning이나 RAG(Retrieval-Augmented Generation) 기반 접근법을 중심으로 발전해 왔다. 그러나 최근에는 여러 LLM이 서로 다른 관점에서 추론하고 상호 검증하는 Multi-Agent 패러다임이 등장하면서, Single-Agent 방식의 한계로 지적되던 Self-Correction 실패, 추론 편향(Bias), 그리고 환각(Hallucination) 문제를 완화하려는 시도가 활발하게 이루어지고 있다.

VulTrial은 이러한 Multi-Agent 패러다임을 소프트웨어 취약점 탐지에 본격적으로 적용한 대표적인 연구라고 생각한다. 특히 실제 법정(Mock-Court)의 구조를 모방하여 검사, 변호인, 판사, 배심원의 역할을 각각 독립적인 에이전트로 구성하고, 서로의 주장을 반박·검증하는 Debate 기반 추론 과정을 설계했다는 점이 매우 인상적이었다. 단순히 여러 LLM을 병렬로 사용하는 것이 아니라, 각 에이전트가 서로 다른 역할과 책임을 수행하도록 설계했다는 점에서 기존 연구와 차별성이 있다고 느꼈다.

다만 Multi-Agent 자체가 모든 문제를 해결해 주는 것은 아니라는 점도 함께 보여준 연구라고 생각한다. 실제 논문에서도 특정 에이전트가 다른 에이전트의 주장에 지나치게 동조하는 Over-alignment 현상이 발생할 수 있음을 실험적으로 분석하였으며, Role-specific Instruction Tuning 과정에서도 이러한 편향이 성능에 영향을 줄 수 있음을 확인하였다. 이는 최근 여러 AI 연구에서 지적되는 Multi-Agent 시스템의 편향 및 협업 실패 문제와도 일맥상통하는 결과라고 볼 수 있다.

개인적으로는 이 논문를 통해 “Multi-Agent를 어떻게 사용할 것인가” 보다 **“Multi-Agent를 어떻게 신뢰할 수 있도록 설계할 것인가”**가 앞으로 더욱 중요한 연구 주제가 될 것이라는 생각이 들었다. 단순히 에이전트 수를 늘리는 것이 아니라, 각 에이전트 간의 균형을 어떻게 유지할 것인지, 특정 에이전트에 대한 편향은 왜 발생하는지, 그리고 이를 어떻게 완화할 것인지가 향후 연구의 핵심 과제가 될 것으로 보인다.

전반적으로 VulTrial은 LLM 기반 취약점 탐지에서 Multi-Agent 패러다임의 가능성을 보여준 중요한 연구이며, 동시에 Multi-Agent 시스템이 앞으로 해결해야 할 새로운 연구 과제까지 함께 제시한 의미 있는 논문이라고 생각한다.
