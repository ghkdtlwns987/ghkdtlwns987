## 문제 설명

전화번호부에 적힌 전화번호 중, **한 번호가 다른 번호의 접두어**인 경우가 있는지 확인하려 합니다.

전화번호가 다음과 같을 경우, 구조대 전화번호는 영석이의 전화번호의 **접두어**입니다.

| 이름 | 번호 |
| --- | --- |
| 구조대 | 119 |
| 박준영 | 97674223 |
| 지영석 | 1195524421 |

`1195524421`은 `119`로 시작하므로, `119`가 `1195524421`의 접두어입니다.

전화번호부에 적힌 전화번호를 담은 배열 `phone_book`이 주어질 때, 어떤 번호가 다른 번호의 접두어인 경우가 있으면 `false`를, 그렇지 않으면 `true`를 return 하도록 solution 함수를 작성해주세요.

제한 사항
- phone_book의 길이는 1 이상 1,000,000 이하입니다.
- 각 전화번호의 길이는 1 이상 20 이하입니다.
- 같은 전화번호가 중복해서 들어있지 않습니다.

입출력 예제

| phone_book | return |
| --- | --- |
| ["119", "97674223", "1195524421"] | false |
| ["123","456","789"] | true |
| ["12","123","1235","567","88"] | false |

입출력 예 설명

입출력 예 #1

`119`가 `1195524421`의 접두어이므로 false입니다.

입출력 예 #2

한 번호가 다른 번호의 접두어인 경우가 없으므로 true입니다.

입출력 예 #3

`12`가 `123`의 접두어이므로 false입니다.

## 문제 풀이

모든 번호 쌍 `(A, B)`에 대해 `B.startswith(A)` 또는 `A.startswith(B)`를 확인하면 풀리지만, 번호가 최대 100만 개라 **O(n²)** 는 시간 초과다.

핵심은 **정렬**이다.

### 핵심 아이디어

전화번호를 **문자열 사전순**으로 정렬하면, 접두어 관계에 있는 두 번호는 **인접**해 있다.

```
정렬 전: ["119", "97674223", "1195524421"]
정렬 후: ["119", "1195524421", "97674223"]
          ↑         ↑
       접두어 관계 → 바로 옆
```

왜 그런가?

`A`가 `B`의 접두어라면, 사전순에서 `A`는 `B`보다 앞에 온다. (짧은 접두어 문자열이 먼저)

그 사이에 다른 번호 `C`가 끼어 있다면, `C`도 `A`로 시작하지 않으면 `A`와 `B` 사이에 들어갈 수 없고, `A`로 시작한다면 `A`의 "확장"이므로 결국 **접두어 체인**이 이어진다. 따라서 **바로 다음 번호**만 보면 접두어 여부를 알 수 있다.

정렬 후 **인접한 두 번호**만 `startswith`로 검사하면 된다.

```
for i in range(1, len(phone_book)):
    if phone_book[i].startswith(phone_book[i - 1]):
        return False
```

### 예제 #3

```
["12", "123", "1235", "567", "88"]
```

정렬 후 순서는 그대로다.

| i | 비교 | 결과 |
| --- | --- | --- |
| 1 | `"123".startswith("12")` | True → false |

`12`와 `123`이 인접하므로 바로 걸린다.

### 해시(Trie)로도 풀 수 있다

정렬 대신 **Trie(접두어 트리)** 에 번호를 넣으면서, 삽입 도중 이미 끝난 노드가 있으면 접두어가 존재하는 것이다. 전화번호·문자열 접두어 문제에서 Trie는 해시/문자열 카테고리의 대표적인 다른 접근이다.

다만 이 문제 규모에서는 **정렬 + 인접 비교**가 구현이 짧고 충분히 빠르다.

---

### Solution

```python
def solution(phone_book):
    phone_book.sort()

    for i in range(1, len(phone_book)):
        if phone_book[i].startswith(phone_book[i - 1]):
            return False
    return True
```

- `sort()` : 문자열 사전순 정렬, O(n log n × L) (L = 번호 길이)
- 인접 쌍만 검사 : O(n × L)
- 접두어가 있으면 `False`, 없으면 `True`

## 정리

| 키워드 | 내용 |
| --- | --- |
| 알고리즘 | 정렬 + 접두어 검사 |
| 핵심 | 정렬 후 **인접한 번호**만 비교 |
| `startswith` | 앞 문자열이 접두어인지 확인 |
| 대안 | Trie |

**접두어 문제 + 문자열**이면 정렬했을 때 접두어 쌍이 붙어 있다는 성질을 떠올리면 된다. brute force 쌍 비교 대신 정렬 한 번으로 범위를 줄이는 것이 포인트다.
