## 문제 설명

당신은 폰켓몬을 잡기 위한 오랜 여행 끝에, 홍 박사님의 연구실에 도착했습니다. 홍 박사님은 당신에게 자신의 연구실에 있는 총 N마리의 폰켓몬 중에서 **N/2마리**를 가져가도 좋다고 했습니다.

홍 박사님 연구실의 폰켓몬은 종류에 따라 번호를 붙여 구분합니다. 따라서 같은 종류의 폰켓몬은 같은 번호를 가지고 있습니다. 예를 들어 연구실에 총 4마리의 폰켓몬이 있고, 각 폰켓몬의 종류 번호가 `[3, 1, 2, 3]`이라면 3번 폰켓몬 두 마리, 1번 폰켓몬 한 마리, 2번 폰켓몬 한 마리가 있는 것입니다.

이때 4마리 중 2마리를 고르는 방법은 6가지가 있습니다.

1. 첫 번째(3), 두 번째(1)
2. 첫 번째(3), 세 번째(2)
3. 첫 번째(3), 네 번째(3)
4. 두 번째(1), 세 번째(2)
5. 두 번째(1), 네 번째(3)
6. 세 번째(2), 네 번째(3)

3번과 4번을 고르면 종류가 1가지(3번만)지만, 나머지 방법은 모두 2가지 종류를 가질 수 있습니다. 따라서 가질 수 있는 **폰켓몬 종류 수의 최댓값**은 2입니다.

N마리 폰켓몬의 종류 번호가 담긴 배열 nums가 주어질 때, N/2마리를 선택하는 방법 중 **가장 많은 종류**를 고를 수 있을 때의 종류 개수를 return 하세요.

제한사항
- nums는 폰켓몬의 종류 번호가 담긴 1차원 배열입니다.
- nums의 길이(N)는 1 이상 10,000 이하의 자연수이며, 항상 짝수로 주어집니다.
- 폰켓몬의 종류 번호는 1 이상 200,000 이하의 자연수로 나타냅니다.
- 가장 많은 종류를 고르는 방법이 여러 가지여도, 종류 개수의 최댓값 하나만 return 하면 됩니다.

입출력 예

| nums | result |
| --- | --- |
| [3,1,2,3] | 2 |
| [3,3,3,2,2,4] | 3 |
| [3,3,3,2,2,2] | 2 |

입출력 예 설명

입출력 예 #1

문제 예시와 같습니다. 4마리 중 2마리를 고를 때 종류 최댓값은 2입니다.

입출력 예 #2

6마리이므로 3마리를 골라야 합니다. 3번, 2번, 4번을 각각 하나씩 고르면 종류 3가지를 가질 수 있습니다.

입출력 예 #3

6마리이므로 3마리를 골라야 합니다. 3번 2마리 + 2번 1마리, 또는 3번 1마리 + 2번 2마리처럼 고를 수 있고, 종류 최댓값은 2입니다.

## 문제 풀이

고를 수 있는 마리 수는 **N/2**로 고정되어 있다. 목표는 그 안에서 **서로 다른 종류**를 최대한 많이 담는 것이다.

두 가지 상한이 있다.

1. **선택 개수 상한** — N/2마리만 고를 수 있으므로, 종류 수는 N/2를 넘을 수 없다.
2. **존재하는 종류 상한** — 연구실에 있는 서로 다른 번호의 개수만큼만 종류를 늘릴 수 있다.

따라서 정답은 다음 둘 중 작은 값이다.

```
min(N/2, 연구실에 존재하는 폰켓몬 종류 수)
```

종류 수는 **중복을 제거**하면 구할 수 있다. Python에서는 `set`을 쓰면 된다.

```python
[3, 1, 2, 3]  →  set  →  {1, 2, 3}  →  len = 3
```

`set`도 내부적으로 **해시 테이블**을 사용한다. 원소를 넣을 때 해시값으로 bucket을 정하고, 같은 값은 한 번만 저장되므로 **중복 제거 + O(1) 평균 조회**가 가능하다. 해시 문제에서 `dict`/`Counter`가 key별 count를 세는 것과 달리, `set`은 **key(원소)의 존재 여부**만 관리한다.

---

### Solution

```python
def solution(nums):
    n = len(nums) // 2
    nums = set(nums)
    return min(n, len(nums))
```

- `n` : 선택할 수 있는 최대 마리 수 (N/2)
- `len(nums)` : set 변환 후 남은 **서로 다른 종류**의 개수
- `min(n, len(nums))` : 두 상한 중 더 작은 값이 정답

예시 `[3, 3, 3, 2, 2, 2]`:

- `n = 3`
- `set(nums) = {2, 3}` → 종류 2가지
- `min(3, 2) = 2`

종류가 2가지뿐이면 3마리를 골라도 서로 다른 번호는 최대 2개까지만 가능하다.

## 정리

| 키워드 | 내용 |
| --- | --- |
| 알고리즘 | 해시 (set) |
| 핵심 | `min(N/2, 고유 종류 수)` |
| set | 중복 제거, 존재 여부 판별 |
| Counter vs set | Counter는 개수, set은 종류만 |

모든 경우를 나열해 조합을 세지 않아도 된다. **선택 개수**와 **고유 종류 수**만 비교하면 충분하다.

```python
# 동일한 의미
return min(len(nums) // 2, len(set(nums)))
```
