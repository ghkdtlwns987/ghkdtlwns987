## 문제 설명

수많은 마라톤 선수들이 마라톤에 참여하였습니다. 단 한 명의 선수를 제외하고는 모든 선수가 마라톤을 완주하였습니다.

마라톤에 참여한 선수들의 이름이 담긴 배열 participant와 완주한 선수들의 이름이 담긴 배열 completion이 주어질 때, 완주하지 못한 선수의 이름을 return 하도록 solution 함수를 작성해주세요.

제한사항
- 마라톤 경기에 참여한 선수의 수는 1명 이상 100,000명 이하입니다.
- completion의 길이는 participant의 길이보다 1 작습니다.
- 참가자의 이름은 1개 이상 20개 이하의 알파벳 소문자로 이루어져 있습니다.
- 참가자 중에는 동명이인이 있을 수 있습니다.

입출력 예

| participant | completion | return |
| --- | --- | --- |
| ["leo", "kiki", "eden"] | ["eden", "kiki"] | "leo" |
| ["marina", "josipa", "nikola", "vinko", "filipa"] | ["josipa", "filipa", "marina", "nikola"] | "vinko" |
| ["mislav", "stanko", "mislav", "ana"] | ["stanko", "ana", "mislav"] | "mislav" |

입출력 예 설명

예제 #1

"leo"는 참여자 명단에는 있지만, 완주자 명단에는 없기 때문에 완주하지 못했습니다.

예제 #2

"vinko"는 참여자 명단에는 있지만, 완주자 명단에는 없기 때문에 완주하지 못했습니다.

예제 #3

"mislav"는 참여자 명단에는 두 명이 있지만, 완주자 명단에는 한 명밖에 없기 때문에 한 명은 완주하지 못했습니다.

---

## 문제 풀이

참가자 명단과 완주자 명단의 차이를 구하면 된다. 단순히 set으로 빼면 **동명이인**을 처리할 수 없다.

예제 #3처럼 `"mislav"`가 participant에 2번, completion에 1번 등장하면, 남은 1명이 정답이다.

따라서 이름별 **등장 횟수**를 세야 하고, 이때 `collections.Counter`를 쓰면 편하다.

### 접근

1. `participant`로 Counter를 만든다. (이름 → 참가 횟수)
2. `completion`에 있는 이름마다 Counter 값을 1씩 줄인다.
3. 값이 0보다 큰 이름이 **완주하지 못한 선수**다.

---

## Counter와 해시

`Counter`는 Python `dict`를 상속한 자료구조로, **해시 테이블** 기반이다.

```python
from collections import Counter

c = Counter(["mislav", "stanko", "mislav", "ana"])
# Counter({'mislav': 2, 'stanko': 1, 'ana': 1})
```

해시에서 조회·저장에 쓰이는 것은 **key**다. `"mislav"`, `"stanko"` 같은 이름이 key이고, 각 key에 대응하는 **value**가 등장 횟수다.

- `c["mislav"]` → key `"mislav"`로 value(2)를 조회
- `c["mislav"] -= 1` → key `"mislav"`의 value를 1 감소

즉 Counter도 dict와 같이 **key로 value에 접근**하는 구조다. value만으로는 특정 이름을 찾을 수 없다.

### `.keys()`, `.values()`, `.items()` 차이

| 메서드 | 반환 | 예시 (`Counter({'mislav': 2, 'ana': 1})`) |
| --- | --- | --- |
| `.keys()` | key만 | `['mislav', 'ana']` |
| `.values()` | value만 | `[2, 1]` |
| `.items()` | (key, value) 쌍 | `[('mislav', 2), ('ana', 1)]` |

이 문제에서는 **이름(key)과 남은 횟수(value)** 를 함께 봐야 하므로 `.items()`를 사용한다.

```python
for name, count in participants.items():
    if count > 0:
        # name이 미완주 선수
```

- `.keys()`만 쓰면 이름은 알 수 있지만, 몇 명 남았는지는 `.values()`를 따로 봐야 한다.
- `.values()`만 쓰면 `[2, 1, 0, ...]`처럼 숫자만 나와 **어느 이름인지** 알 수 없다.
- `.items()`는 `(이름, 횟수)`를 한 번에 돌릴 수 있어 이 문제에 적합하다.

---

### Solution

```python
from collections import Counter

def solution(participant, completion):
    participants = Counter(participant)

    for i in completion:
        if i in participants:
            participants[i] -= 1

    stack = []
    for a, b in participants.items():
        if b > 0:
            stack.append(a)

    answer = "".join(stack)
    return answer
```

`completion`을 순회하며 해당 이름의 count를 1씩 빼고, 마지막에 count가 0보다 큰 key를 찾는다.

문제 조건상 미완주 선수는 **항상 1명**이므로 `stack`에는 이름이 하나만 들어간다.

## 정리

| 키워드 | 내용 |
| --- | --- |
| 알고리즘 | 해시 (Counter) |
| 핵심 | 이름별 등장 횟수 비교 |
| 주의 | 동명이인 → set만으로는 불가 |
| Counter | key=이름, value=횟수 |

동명이인이 있는 **개수 비교** 문제는 Counter나 dict로 key별 count를 세는 방식이 자주 쓰인다.

```python
# 한 줄로도 가능 (참고)
(Counter(participant) - Counter(completion)).most_common(1)[0][0]
```

위처럼 Counter끼리 빼면 남은 key가 바로 정답이지만, `.items()`로 직접 순회하는 방식이 Counter 동작을 이해하기에는 더 명확하다.
