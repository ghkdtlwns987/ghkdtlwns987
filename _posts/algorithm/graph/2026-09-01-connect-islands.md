## 문제 설명

n개의 섬 사이에 다리를 건설하는 비용(costs)이 주어질 때, 최소의 비용으로 모든 섬이 서로 통행 가능하도록 만들 때 필요한 최소 비용을 return 하도록 solution을 완성하세요.

다리를 여러 번 건너더라도, 도달할 수만 있으면 통행 가능하다고 봅니다. 예를 들어 A 섬과 B 섬 사이에 다리가 있고, B 섬과 C 섬 사이에 다리가 있으면 A 섬과 C 섬은 서로 통행 가능합니다.

제한사항
- 섬의 개수 n은 1 이상 100 이하입니다.
- costs의 길이는 ((n-1) * n) / 2 이하입니다.
- 임의의 i에 대해, costs[i][0]와 costs[i][1]에는 다리가 연결되는 두 섬의 번호가 들어있고, costs[i][2]에는 이 두 섬을 연결하는 다리를 건설할 때 드는 비용입니다.
- 같은 연결은 두 번 주어지지 않습니다. 또한 순서가 바뀌더라도 같은 연결로 봅니다. 즉 0과 1 사이를 연결하는 비용이 주어졌을 때, 1과 0의 비용이 주어지지 않습니다.
- 모든 섬 사이의 다리 건설 비용이 주어지지 않습니다. 이 경우, 두 섬 사이의 건설이 불가능한 것으로 봅니다.
- 연결할 수 없는 섬은 주어지지 않습니다.

입출력 예

| n | costs | return |
| --- | --- | --- |
| 4 | [[0,1,1],[0,2,2],[1,2,5],[1,3,1],[2,3,8]] | 4 |

입출력 예 설명

주어진 costs를 그래프로 표현하면 다음과 같습니다.

```
        (1)
    0 ----- 1
    |   \     |
 (2)|    \(5) | (1)
    |       \ |
    2 ------- 3
         (8)
```

가능한 다리: (0,1)=1, (0,2)=2, (1,2)=5, (1,3)=1, (2,3)=8

모든 섬을 연결하면서 비용을 최소화하려면 아래 3개의 다리를 선택하면 됩니다.

```
0 --1-- 1 --1-- 3
|
2
(비용 2)
```

- 0-1 : 1
- 1-3 : 1
- 0-2 : 2

총 비용 **4**가 정답입니다.

## 문제 풀이

모든 섬이 **서로 도달 가능**해야 하고, 선택한 다리의 **비용 합이 최소**여야 한다.

이 조건은 그래프에서 **모든 정점을 연결하는 트리**를 만들되, 간선 가중치의 합이 최소인 **최소 신장 트리(MST, Minimum Spanning Tree)** 를 구하는 문제와 같다.

섬이 n개이면 트리를 만들려면 정확히 **n-1개의 다리**가 필요하다.

MST를 구하는 대표적인 방법은 **Kruskal**과 **Prim**이다. 이 문제에서는 간선 목록이 `costs`로 주어지므로 **Kruskal + Union-Find**가 구현하기 편하다.

### Kruskal 알고리즘

1. 모든 간선을 **비용 오름차순**으로 정렬한다.
2. 비용이 작은 간선부터 하나씩 본다.
3. 해당 간선을 선택했을 때 **사이클이 생기지 않으면** MST에 포함한다.
4. MST에 포함된 간선이 **n-1개**가 되면 종료한다.

사이클 여부는 **Union-Find(서로소 집합)** 로 확인한다. 두 섬의 루트가 같으면 이미 연결되어 있으므로 
---

### Solution

```python
def solution(n, costs):
    costs.sort(key = lambda x : x[2])
    parent = [i for i in range(n + 1)]
    
    def find(x):
        if parent[x] != x:
            parent[x] = find(parent[x])
        return parent[x]
    
    def union(a, b):
        a = find(a)
        b = find(b)
        
        if a != b:
            parent[b] = a
    
    answer = 0
    
    for a, b, cost in costs:
        if find(a) != find(b):
            union(a, b)
            answer += cost
    
    return answer
```

- `find`에서 **경로 압축**을 사용하면 Union-Find 성능이 좋아진다.
- 간선을 비용 순으로 정렬한 뒤, 사이클 없이 n-1개를 고르면 그 합이 MST의 최소 비용이다.

| 키워드 | 내용 |
| --- | --- |
| 알고리즘 | MST (Kruskal) |
| 자료구조 | Union-Find |
| 정렬 기준 | 간선 비용 오름차순 |
| 선택 개수 | n - 1개 |

**모든 정점을 최소 비용으로 연결**하는 문제는 MST를 떠올리면 된다. 간선 리스트가 주어지면 Kruskal, 인접 리스트 그래프가 주어지면 Prim도 고려할 수 있다.
