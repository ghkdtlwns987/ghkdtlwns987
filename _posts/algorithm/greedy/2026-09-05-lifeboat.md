## 문제 설명

무인도에 갇힌 사람들을 구명보트로 구출하려고 합니다. 구명보트는 한 번에 **최대 2명**만 탈 수 있고, 무게 제한도 있습니다.

예를 들어 몸무게가 `[70kg, 50kg, 80kg, 50kg]`이고 제한이 100kg이면, 2번째와 4번째(50+50)는 같이 탈 수 있지만 1번째와 3번째(70+80=150)는 제한을 초과합니다.

구명보트를 **최대한 적게** 써서 모든 사람을 구출하려고 합니다.

`people`(몸무게 배열)과 `limit`(무게 제한)이 주어질 때, 필요한 구명보트 개수의 최솟값을 return 하세요.

제한사항
- 사람은 1명 이상 50,000명 이하
- 몸무게는 40kg 이상 240kg 이하
- `limit`은 40 이상 240 이하
- `limit`은 항상 몸무게 최댓값보다 크므로, 구출 불가능한 경우는 없음

입출력 예

| people | limit | return |
| --- | --- | --- |
| [70, 50, 80, 50] | 100 | 3 |
| [70, 80, 50] | 100 | 3 |

예제 1: (50, 50), (70), (80) → 보트 3척. 예제 2: 50과 70이 같이 못 타므로 3척.

## 가벼운 사람끼리 태우면 손해다

한 보트에 최대 2명이라, 매번 "누구와 누구를 태울지"만 정하면 된다. 사람은 최대 5만 명이라 모든 짝을 탐색할 수 없고, **그리디**로 한 명씩 처리해야 한다.

직관적으로는 가벼운 사람부터 둘씩 태우고 싶을 수 있다. 반례가 있다.

```text
people = [10, 10, 80, 90], limit = 100

가벼운 사람끼리:
  10 + 10 → 1척
  80      → 1척
  90      → 1척
  총 3척

가벼운 사람 + 무거운 사람:
  10 + 90 → 1척
  10 + 80 → 1척
  총 2척
```

무거운 사람은 혼자 탈 가능성이 크다. 그 옆에 **가장 가벼운 사람**을 넣을 수 있으면 넣는 것이 보트를 아끼는 길이다. 가벼운 사람끼리 먼저 묶어 버리면, 무거운 사람을 받아 줄 짝이 없어진다.

그래서 매 순간:

```text
가장 가벼운 사람 + 가장 무거운 사람  <= limit  →  둘이 같이
아니면                                 →  무거운 사람만
```

## 투 포인터

몸무게를 정렬하면 왼쪽이 최솟값, 오른쪽이 최댓값이다.

```text
sorted: [50, 50, 70, 80]   limit 100
         ↑             ↑
       start          end
```

- `people[start] + people[end] <= limit` 이면 둘 다 태운다 → `start += 1`, `end -= 1`
- 아니면 무거운 쪽만 태운다 → `end -= 1`
- 한 번 태울 때마다 보트 1척 (`answer += 1`)
- `start > end`가 되면 전원 구출

예제 1 추적:

```text
50 + 80 = 130 > 100  →  80만     보트 1
50 + 70 = 120 > 100  →  70만     보트 2
50 + 50 = 100 <= 100 →  둘 다    보트 3
```

`start == end`이면 한 명만 남은 것이다. 그 사람 혼자 태우고 끝난다. (`2 * 몸무게`가 limit 이하든 초과든, 포인터가 그 한 명을 벗어나고 보트는 1척이다.)

limit이 최댓값보다 크다는 조건 때문에, 무거운 사람은 항상 혼자라도 탈 수 있다.

---

### Solution (투 포인터)

```python
def solution(people, limit):
    people.sort()

    # 반례를 생각해보자.
    """
    [10, 10, 80, 90] 라는 예시가 있다면,
    10 + 10(20) -> 1
    80 -> 1
    90 -> 1

    하지만,

    10 + 90 -> 1
    10 + 80 -> 1
    총 2가지의 경우의 수가 나온다.
    따라서, 최소 + 최대 기준으로 계산해야 한다.
    """

    start = 0
    end = len(people) - 1
    answer = 0
    while start <= end:
        if people[start] + people[end] <= limit:
            start += 1
            end -= 1
        else:
            end -= 1
        answer += 1

    return answer
```

- `people.sort()` : 왼쪽 최소, 오른쪽 최대
- 같이 탈 수 있으면 `start`, `end` 둘 다 이동. 아니면 무거운 `end`만 이동
- 루프 한 번 = 보트 한 척. 모든 사람이 한 번씩 빠진다
- 정렬 O(n log n) + 투 포인터 O(n). n ≤ 50,000이면 충분하다

## deque로도 풀 수 있다

같은 그리디를 **양끝 큐**로 표현할 수도 있다. 정렬해 두면 왼쪽이 최솟값, 오른쪽이 최댓값이다. `pop()`이 무거운 사람, `popleft()`가 가벼운 사람이다.

인덱스를 `start`/`end`로 움직이는 대신, 실제로 태운 사람을 큐에서 빼면 된다.

```text
q = deque(정렬된 people)

q가 빌 때까지:
  heavy = 오른쪽(가장 무거움)을 꺼낸다
  남은 사람이 있고, heavy + 왼쪽(가장 가벼움) <= limit 이면
    왼쪽도 꺼낸다
  보트 += 1
```

`if q and ...` 가 중요하다. 마지막 한 명만 남았을 때 `q[0]`을 보면 안 된다. 무거운 사람을 이미 `pop()` 했으므로, 큐가 비어 있으면 그 한 명만 태우고 끝이다.

투 포인터의 `end -= 1`이 `q.pop()`, `start += 1`이 `q.popleft()`에 해당한다.

### Solution (deque)

```python
def solution(people, limit):
    from collections import deque
    people.sort()
    q = deque(people)
    answer = 0
    while q:
        heavy = q.pop()

        if q and heavy + q[0] <= limit:
            q.popleft()

        answer += 1
    return answer
```

- `q.pop()` : 가장 무거운 사람은 항상 탄다
- `q.popleft()` : 같이 탈 수 있을 때만 가장 가벼운 사람을 태운다
- 큐가 빌 때까지 반복. 루프 한 번 = 보트 한 척

의미는 투 포인터와 같다. 포인터로 구간을 줄일지, 덱에서 양쪽을 뺄지만 다르다.

## 정리

| 키워드 | 내용 |
| --- | --- |
| 알고리즘 | 그리디 + 투 포인터 (또는 deque) |
| 제약 | 한 보트 최대 2명, 무게 ≤ limit |
| 그리디 | **가장 가벼운 사람 + 가장 무거운 사람**을 짝 지을지 먼저 본다 |
| 반례 | 가벼운 사람끼리 묶으면 무거운 사람이 혼자 남음 |
| 답 | 루프마다 보트 1척, 전원 태울 때까지 |

보트를 아끼려면 혼자 타야 하는 무거운 사람 자리에, 탈 수 있는 **가장 가벼운 사람**을 끼워 넣는 것이 이득이다. 구현은 인덱스 두 개로 해도 되고, `deque`의 양끝 `pop`으로 해도 된다.
