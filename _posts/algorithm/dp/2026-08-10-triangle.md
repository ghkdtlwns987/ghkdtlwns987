# 문제
문제 링크 : https://school.programmers.co.kr/learn/courses/30/lessons/43105



## 문제 설명
문제 설명  
7  
3 8  
8 1 0  
2 7 4 4  
4 5 2 6 5   

위와 같은 삼각형의 꼭대기에서 바닥까지 이어지는 경로 중, 거쳐간 숫자의 합이 가장 큰 경우를 찾아보려고 합니다. 아래 칸으로 이동할 때는 대각선 방향으로 한 칸 오른쪽 또는 왼쪽으로만 이동 가능합니다. 예를 들어 3에서는 그 아래칸의 8 또는 1로만 이동이 가능합니다.

삼각형의 정보가 담긴 배열 triangle이 매개변수로 주어질 때, 거쳐간 숫자의 최댓값을 return 하도록 solution 함수를 완성하세요.

제한사항
삼각형의 높이는 1 이상 500 이하입니다.
삼각형을 이루고 있는 숫자는 0 이상 9,999 이하의 정수입니다.
입출력 예
triangle	result
[[7], [3, 8], [8, 1, 0], [2, 7, 4, 4], [4, 5, 2, 6, 5]]	30
## 문제 풀이
처음 이 문제를 보면 `BFS/DFS` 로 풀어야 겠다는 생각이 들었다.  
하지만 시간복잡도를 계산해보면, 그 이야기가 달라진다.  
`level` 당 2번의 계산을 해야하고, level 의 최대가 `500` 이므로  
시간 복잡도는 `2^500` 이 되어 버린다. 따라서 이 문제는 DP 문제라고 할 수 있다.  

가장 먼저, 생각해 보아야 할게, `대각선 왼쪽과 오른쪽으로만 이동이 가능하다.` 이며 `triangle의 (level, col), (level, col)` 에 이전 상태를 더해주면 된다.  

이는 곧 다음과 같이 표현할 수 있다.  
```python
dp[level][col] = max(triangle[level][col] + dp[level - 1][col], triangle[level][col] + dp[level] - 1][col - 1])
```

이 때 하나 주의할 점이  삼각형의 `맨 끝부분과` `맨 마지막 부분` 은 *별도로 계산해 주어야 한다.* 그 이유는 삼각형의 맨 왼쪽 가장자리를 계산할 때는 삼각형의 오른 대각선의 값을 더하지 않는다. 이와 마찬가지로, 삼각형의 맨 오른쪽 가장자리는 삼각형의 왼쪽 대각선의 값을 더하지 않기 때문이다. 

따라서 해답은 다음과 같다.
### Solution

```python
def solution(triangle):
    dp = [[0] * 502 for _ in range(502)]
    dp[0] = triangle[0]
    
    for level in range(1, len(triangle)):
        for col in range(len(triangle[level])):
            if col == 0:
                dp[level][col] = (triangle[level][col] + dp[level - 1][col])
            elif col == len(triangle[level]) - 1:
                dp[level][col] = (triangle[level][col] + dp[level - 1][col - 1])
            else:
                dp[level][col] = max((triangle[level][col] + dp[level - 1][col]), (triangle[level][col] + dp[level - 1][col - 1]))
    
    return max(max(dp))
```
