# 문제
문제 링크 : https://school.programmers.co.kr/learn/courses/30/lessons/42895



## 문제 설명 : 

아래와 같이 5와 사칙연산만으로 12를 표현할 수 있습니다.

```
12 = 5 + 5 + (5 / 5) + (5 / 5)
12 = 55 / 5 + 5 / 5
12 = (55 + 5) / 5
```

5를 사용한 횟수는 각각 6, 5, 4입니다. 그리고 이중 가장 작은 경우는 4입니다.
이처럼 숫자 N과 number가 주어질 때, N과 사칙연산만 사용해서 표현할 수 있는 방법 중 N 사용횟수의 최솟값을 return 하도록 solution 함수를 작성하세요.

### 제한사항

- N은 1 이상 9 이하입니다.
- number는 1 이상 32,000 이하입니다.
- 수식에는 괄호와 사칙연산만 가능하며 나누기 연산에서 나머지는 무시합니다.
- 최솟값이 8보다 크면 -1을 return 합니다.

### 입출력 예

| N | number | return |
|---|--------|--------|
| 5 | 12     | 4      |
| 2 | 11     | 3      |

### 입출력 예 설명

**예제 #1** — 문제에 나온 예와 같습니다.

**예제 #2** — 11 = 22 / 2와 같이 2를 3번만 사용하여 표현할 수 있습니다.

## 문제 풀이

이 문제는 **Dynamic Programming(DP)** 을 이용하여 해결할 수 있다.

처음에는 어떻게 DP를 적용해야 할지 감이 오지 않았지만, 핵심은 **N을 사용한 횟수를 기준으로 문제를 나누는 것**이다.

`dp[i]`를 **N을 정확히 i번 사용하여 만들 수 있는 모든 숫자의 집합(Set)** 이라고 정의한다.

예를 들어 `N = 5`라면

```text
dp[1] = {5}
dp[2] = {
    55,
    5 + 5,
    5 - 5,
    5 * 5,
    5 // 5
}
```

과 같이 정의할 수 있다.

또한 `55`, `555`, `5555`처럼 **N을 이어 붙인 숫자도 하나의 경우**이므로, 각 `dp[i]`를 초기화할 때 반드시 포함해야 한다.

이제 `dp[i]`를 만들기 위해서는 **앞부분과 뒷부분으로 나누어 생각**하면 된다.

예를 들어 `dp[4]`를 만든다면

```text
4 = 1 + 3
4 = 2 + 2
4 = 3 + 1
```

세 가지 경우를 모두 고려한다.

즉,

- `dp[1]`의 모든 값과 `dp[3]`의 모든 값을 사칙연산
- `dp[2]`의 모든 값과 `dp[2]`의 모든 값을 사칙연산
- `dp[3]`의 모든 값과 `dp[1]`의 모든 값을 사칙연산

하여 나온 결과를 모두 `dp[4]`에 추가한다.

이 과정을 `dp[8]`까지 반복하면서 `number`가 등장하는 가장 작은 사용 횟수를 찾으면 된다.

따라서 점화식은 다음과 같다.

```python
dp[i] = {NNN... N(i개)}
dp[j] op dp[i - j]
```

### Solution

```python
def solution(N, number):
    if N == number:
        return 1

    answer = -1
    dp = [set() for _ in range(8)]

    for i in range(len(dp)):
        dp[i].add(int(str(N) * (i + 1)))

    for i in range(1, 8):
        for j in range(0, i):
            for op1 in dp[i - j - 1]:
                for op2 in dp[j]:
                    dp[i].add(op1 + op2)
                    dp[i].add(op1 - op2)
                    dp[i].add(op1 * op2)
                    if op2 != 0:
                        dp[i].add(op1 // op2)

        if number in dp[i]:
            answer = i + 1
            break

    return answer
```
