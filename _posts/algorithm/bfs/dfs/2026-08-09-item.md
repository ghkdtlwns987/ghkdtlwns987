## 문제 풀이
문제 접근

캐릭터는 여러 직사각형으로 이루어진 도형의 테두리만 따라서 이동할 수 있다.
따라서 이 문제는 다음과 같이 생각할 수 있다.

직사각형들의 테두리를 이동 가능한 길로 만든 뒤, 캐릭터의 위치에서 아이템의 위치까지 BFS로 최단거리를 구한다.

단순히 BFS를 수행하는 것 자체는 어렵지 않다.
이 문제에서 중요한 부분은 직사각형의 테두리를 정확하게 배열에 표현하는 것이다.

전체적인 과정은 다음과 같다.

1. 모든 좌표를 2배 한다.
2. 직사각형 영역을 배열에 표시한다.
3. 직사각형 내부를 제거하여 테두리만 남긴다.
4. 캐릭터 위치에서 BFS를 수행한다.
5. 아이템까지의 최단거리를 구한다.
6. 좌표를 2배 했으므로 최종 거리를 2로 나눈다.

이 순서대로 하면 되는데, 중요한 점은
`모든 좌표를 2배로 계산하는 것`, `직사각형을 그릴 때, 사각형을 모두 채우고 나서 안을 비우는 것` 이다.

`모든 좌표를 2배로 계산하는 것` : 처음에는 단순히 주어진 좌표를 그대로 배열에 표현하면 될 것 같지만, 그렇게 하면 서로 다른 테두리가 배열에서 붙어 있는 것처럼 표현되는 경우가 발생할 수 있다.

`직사각형을 그릴 때, 사각형을 모두 채우고 나서 안을 비우는 것` : 여러 직사각형이 존재하기 때문에 다음과 같이 처리하면 문제가 발생할 수 있다.

```
첫 번째 직사각형 채우기
-> 첫 번째 직사각형 내부 제거

두 번째 직사각형 채우기
-> 두 번째 직사각형 내부 제거
```

따라서, 뒤에서 처리하는 직사각형이 앞에서 이미 제거한 내부를 다시 1로 만들 수 있기 때문이다.

### Solution

```python
def solution(rectangle, characterX, characterY, itemX, itemY):
    M = 102
    arr = [[0] * M for _ in range(M)]
    visited = [[0] * M for _ in range(M)]
    characterX *= 2
    characterY *= 2
    itemX *= 2
    itemY *= 2
    
    for x1, y1, x2, y2 in rectangle:
        x1 *= 2
        y1 *= 2
        x2 *= 2
        y2 *= 2
        
        for y in range(y1, y2 + 1):
            for x in range(x1, x2 + 1):
                arr[y][x] = 1
        
    for x1, y1, x2, y2 in rectangle:
        x1 *= 2
        y1 *= 2
        x2 *= 2
        y2 *= 2
        
        for y in range(y1 + 1, y2):
            for x in range(x1 + 1, x2):
                arr[y][x] = 0
        
    
    
    """
    for i in range(11):
        for j in range(11):
            print(arr[i][j], end = " ")
        print()
    """
    
    from collections import deque
    q = deque()
    q.append((characterY, characterX))
    visited[characterY][characterX] = 1
    dy = [-1, 1, 0, 0]
    dx = [0, 0, 1, -1]
    while q:
        y, x = q.popleft()
        if y == itemY and x == itemX:
            return visited[itemY][itemX] // 2
        
        for i in range(4):
            ny = dy[i] + y
            nx = dx[i] + x
            
            if ny >= M or nx >= M or ny < 0 or nx < 0:
                continue
            if arr[ny][nx] == 0:
                continue
            if visited[ny][nx]:
                continue
            
            visited[ny][nx] = visited[y][x] + 1
            q.append((ny, nx))

```
